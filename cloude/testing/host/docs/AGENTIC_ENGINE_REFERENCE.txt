1. ARCHITECTURE (ONE PAGE)
================================================================================

  Chrome extension (Kaggle /edit tab)
       │ scrapes cells → live JSON
       │ executes browser tools (click, edit, run)
       ▼
  host.py  ←── CHAT_REQUEST, GET_HISTORY, STOP_CHAT
       │
       ├── memory.py          SQLite chat history
       ├── notebook_context   pack_context() / snapshots
       ├── prompt_engineering build_system_content(), build_chat_messages()
       ├── notebook_query     host prefetch (read tools)
       └── streaming.py       LLM orchestration + two-phase agentic flow
                │
                ├── agentic_text_tools.py   parse <agent_tool_batch>
                ├── agentic_batch_executor.py queue writes + runs
                └── tool_registry.py        local + browser tools

MODES (UI dropdown):
  ask     — read-only advice, prose replies
  code    — generate code + Placement instructions (no browser writes)
  agentic — browser write tools + two-phase flow (needs dashboard toggle)

AGENTIC GATES (all required):
  1. LLM_AGENTIC_ENABLED=1 in .env
  2. Dashboard toggle ON → data/meta/agentic_settings.json {"dashboard_enabled": true}
  3. UI mode = agentic

================================================================================
2. REQUEST FLOW (host.py → streaming.py)
================================================================================

CHAT_REQUEST handler (host.py):
  1. history_key = notebook identity (URL slug or kaggle:kernel:ID)
  2. session_id = UI conversation UUID
  3. cell_num = msg.cellIndex OR _extract_cell_number(prompt) OR resolve_cell_index(prompt, cells)
     - "last cell" → last code cell with error output, else last non-empty code cell
  4. mode = detect_mode(ui_mode)  — uses UI selection only (ask/code/agentic)
  5. pack_context(mode, url, prompt, cell_index) → ContextPack text (unless static cache)
  6. memory_session_id = effective_session_id(session_id, mode)
     - CHAT_SESSION_PER_MODE=0 (default): same session for all modes
     - CHAT_SESSION_PER_MODE=1: session_id::mode::ask|code|agentic
  7. If CEREBRAS_STATIC_NOTEBOOK_CACHE:
       context = frozen baseline (session start)
       turn_tail = live delta + profile
     Else:
       context = merged notebook pack + profile facts
  8. history = memory_store.get_history(history_key, memory_session_id)
  9. memory_store.append(user prompt)  — BEFORE stream starts
 10. Thread → _run_streaming_chat(..., context_meta)

_run_streaming_chat (streaming.py):
  1. build_chat_messages(mode, history, context, turn_tail, text_tool_calls?)
  2. If mode in {ask, code, agentic}: prefetch_notebook_queries → prepend to user message
  3. fit_messages_to_budget()
  4. If agentic:
       a. Skip Ask/Code prose stream; emit "Working…" and enter tool rounds
       b. Parse <agent_tool_batch> from LLM text (Cerebras path) OR native tool_calls
       c. execute_agentic_batch() — host runs full queue per phase
       d. Default (AGENTIC_FIRE_AND_FORGET=1): two LLM calls — round 0 reads,
          round 1 implementation tool_calls; host dispatch summary; stop
       e. Non-default (AGENTIC_FIRE_AND_FORGET=0): verification follow-up on
          error — extra LLM round (max LLM_REACT_MAX_ROUNDS; legacy env name)
       f. Final summary or dispatch text persisted to history
  5. memory_store.append(assistant final_text) unless stopped

================================================================================
3. CHAT HISTORY STRUCTURE
================================================================================

STORAGE: SQLite at data/sessions/chat_history.sqlite3

TABLE messages:
  id            INTEGER PK
  notebook_url  TEXT     — history_key (e.g. kaggle:kernel:112732919 or URL slug)
  session_id    TEXT     — UI session UUID (or suffixed per-mode if CHAT_SESSION_PER_MODE=1)
  role          TEXT     — "user" | "assistant"
  content       TEXT     — full message text
  timestamp     TEXT     — ISO UTC

TABLE profile_facts:
  notebook_url, session_id, fact_key, fact_value, updated_at
  — e.g. user name from "my name is Alice"

LIMITS (config.py):
  MAX_HISTORY_MESSAGES=24        — loaded from DB for UI + passed to streaming
  MAX_HISTORY_MESSAGES_API       — 3 (full context pack) or 10 (intent); min 2 if static cache
  MAX_HISTORY_CHARS_PER_MSG=1000 — trim_history_for_api truncates each turn

SHARED ACROSS MODES (default):
  ask, code, agentic append to SAME session_id bucket unless CHAT_SESSION_PER_MODE=1

WHAT GOES TO LLM (build_chat_messages):
  [
    {"role": "system", "content": "<full assembled system prompt>"},
    ... trimmed history (user/assistant alternating) ...
    {"role": "user", "content": "<turn_tail>\n\n---\n\n<prompt>\n\n<prefetch block may be prepended in streaming>"}
  ]

NOT stored in history:
  - Tool batch JSON / verification payloads (in-memory for current turn only)
  - Prefetch blocks (recomputed each turn)
  - Intermediate tool-round payloads (only final assistant text persisted)

STOP behavior:
  - If user presses Stop: no assistant append; stream ends with stopped=true

CELL DEBUG CHAT (separate):
  session_id = "cell-debug-cell-N" — not shared with main chat

4. MESSAGE / CONTEXT LAYERS (what the LLM sees)
================================================================================

SYSTEM PROMPT SECTIONS (order — build_system_content):
  ## Role       — base_notebook_assistant + mode file + "Active UI mode: **X**"
  ## Task       — mode-specific task
  ## Specifics  — mode-specific rules
  ## Context    — jupyter model, query guidance, notebook URL, tool calling docs,
                  tool descriptions, ### Notebook evidence (context pack OR baseline)
  ## Examples   — mode examples + tool argument examples
  ## Notes      — mode notes + base notes + _SYSTEM_NOTES_{ASK|CODE|AGENTIC}

USER MESSAGE (current turn):
  [Optional turn_tail]
    - Live notebook delta (cells changed since session baseline)
    - User profile facts
  ---
  [Optional prefetch block from host read tools]
  ---
  User prompt

STATIC CACHE (Cerebras):
  - System "Notebook evidence" = frozen baseline at first message of session
  - Delta block on user turn only → avoids rewriting system prefix (prompt cache)
  - Baseline caps: BASELINE_MAX_CELL_INPUT_CHARS=1500, OUTPUT=350, TOTAL=10000

CONTEXT PACK MODES (CONTEXT_PACK_MODE env):
  intent — slice by ask sub-intent (error, explain, placement, …)
  full   — more cells in system context

ASK sub-intents (classify_ask_intent — not separate UI modes):
  placement | error | dependency | review | explain | general | dataset

6. SYSTEM NOTES (appended last in every mode — prompt_engineering.py)
================================================================================

ASK (_SYSTEM_NOTES_ASK):
- Read CONTEXT_MANIFEST and TARGET_CELL_STATUS before citing any cell.
- Only cite cells in listed_cells or notebook evidence — never invent cell contents.
- Empty target cell: acknowledge, ask what user wants, suggest 1–2 options — no code dump yet.
- Reply directly. No meta preamble. No UI button language.
- Clean Markdown. If coverage none/partial → **INSUFFICIENT_CONTEXT**.

CODE (_SYSTEM_NOTES_CODE):
- Same manifest rules.
- Empty cell → ask intent first.
- New scripts → Insert below defining cell.
- User reply: Placement bullets + one python block when generating.
- INSUFFICIENT_CONTEXT if tools lack data.

CODE+REACT (_SYSTEM_NOTES_CODE_REACT) — legacy if react on code:
- One atomic browser tool per round; chain insert→edit→run.

AGENTIC (_SYSTEM_NOTES_AGENTIC):
- One assistant message = ALL tool_calls for the task.
- Pass exact notebook URL on every tool call.
- No Placement / Run order prose — tool_calls only until queue completes.
- Summarize only after tool_queue_status is complete.

## Task

12. AGENTIC BATCH EXECUTOR (agentic_batch_executor.py)
================================================================================

Entry: execute_agentic_batch(tool_calls, user_prompt, url, tab_id, registry, ...)

Constants:
  INTER_TOOL_DELAY_SEC = 0.5
  RUN_WAIT_TIMEOUT_SEC = 120
  MAX_CELL_OUTPUT_CHARS = 8000

Queue order:
  1. Local read tools (notebook_*)
  2. Writes: insert_cell, edit_cell_by_index, delete_by_index, … (0.5s spacing)
  3. Run queue: run_cell sequential, wait for scrape output, detect errors

Verification payload (returned to LLM as tool result JSON):
  tool_queue_status: "complete" | "error" | ...
  tool_queue_complete / run_queue_complete
  queue_cell_evidence: [{cell_index, input, output, has_error, ...}, ...]
  runs_executed: [indices]
  error_recovery: {failed_cell, pending_runs, propagation_hint, user_task}  (on error)
  pipeline: {active, complete, pending_runs, last_run, next_cell}  (multi-turn pipelines)
  close_react_loop / continue_react_loop / await_llm_summary
  (internal flag names; legacy "react" naming — not a user-facing ReAct loop)

Error recovery (agentic_action_guard.py) — non-default path (AGENTIC_FIRE_AND_FORGET=0):
  MAX_ERROR_RECOVERY_ROUNDS = 4
  If queue stops on cell error → nudge LLM to fix + re-batch (not prose-only)

Cancel: cancel_check from streaming _is_stopped() — user Stop button

13. AGENTIC TWO-PHASE FLOW (streaming.py summary)
================================================================================

Default (AGENTIC_FIRE_AND_FORGET=1, AGENTIC_MAX_TOOL_ROUNDS=2):
  max_tool_rounds = 2 per user message

  First LLM call (round 0 — query phase):
    - build_chat_messages + prefetch
    - Non-streaming LLM call with tools enabled
    - Host strips write tools when AGENTIC_MANDATORY_TWO_PHASE=1
    - parse_text_tool_batch or native tool_calls → execute_agentic_batch (reads)
    - Phase-1 implementation nudge appended

  Second LLM call (round 1 — implementation / tool_calls phase):
    - Host strips query tools from batch
    - LLM emits write + run tools in one assistant message
    - execute_agentic_batch() dispatches browser tools
    - Host emits dispatch summary; loop ends

Non-default (AGENTIC_FIRE_AND_FORGET=0):
  max_tool_rounds = LLM_REACT_MAX_ROUNDS (default 15; legacy env name)
  Verification follow-up when workflow_needs_llm_followup() or queue errors:
    - Error recovery nudge injected if tool_queue_status=error
    - Additional LLM call may emit new tool batch
    - Bounded by caps (MAX_ERROR_RECOVERY_ROUNDS, etc.)
    - Not an open-ended ReAct loop

Action tail (when cell known):
  "Target cell is N. Emit one <agent_tool_batch>: edit_cell_by_index cell_index=N, ..."

14. CELL INDEX RESOLUTION (prompt_utils.py)
================================================================================

_extract_cell_number(prompt):
  Patterns: "cell 5", "cell#5", "3rd cell", "first cell" (0-based for ordinals!), index 4

resolve_cell_index(prompt, cells):
  1. Explicit number from _extract_cell_number
  2. "last cell" / "final cell" → last code cell with Traceback/error in output
  3. Else last non-empty code cell
  4. Else max code cell index
