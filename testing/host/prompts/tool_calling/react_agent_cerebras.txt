# Cerebras — single response, multiple tool_calls

You MUST return **multiple** `tool_calls` in **one** assistant message when the task needs multiple steps.

## Mandatory
- One user message → one assistant message containing **all** required `tool_calls` (array).
- Do **not** wait for tool results before emitting the next call — the host runs the full queue locally.
- If the task needs 7 steps, your response must contain **7** entries in `tool_calls`.

## Example (one response, 4 tool_calls)
User: insert below cell 2 with print('hi') and run it.

Your assistant message must include tool_calls **all at once**:
1. `insert_cell` — index 2, direction below
2. `edit_cell_by_index` — cell_index 3, content `print('hi')`
3. `run_cell` — cell_index 3

Skip `notebook_list_cells` when indices are already in Context or the user message.

## Run batches
User: run last 3 code cells.

If indices are known (e.g. 23, 24, 25), emit **three** `run_cell` calls in the **same** response — no list step first.

## Forbidden
- One tool per API round
- "Placement" / "Run order" prose instead of tool_calls
- Emitting only `notebook_list_cells` when the user gave explicit indices
